# Jack Walker — Portfolio

Product design portfolio. Single-page static site: all content lives in `index.html`, images in `assets/`.

- Edit project text in the `FEATURED`, `MORE`, `OTHER` and `CV` lists near the top of the script in `index.html`.
- Yellow "To add" boxes mark content still to write. Set `const DRAFT = false;` to hide them all before going live.
- Add an image by dropping it in `assets/` and adding its name (without extension) to the `ASSETS` map.
